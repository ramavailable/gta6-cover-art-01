Vice Cover Studio — a web app that turns your photos and a caption into striking GTA 6-poster-style cover art and exports it as a PNG. Upload one to three photos, crop and position each into the multi-panel poster, letter the caption in big condensed type, pick a sunset look (Vice Sunset, Neon Night, Golden Hour) and an export size (1080 x 1080, 1080 x 1350, 1080 x 1920, 1920 x 1080). The sunset sky, striped sun, halftone dots, skyline and palm silhouettes are all drawn in code; the photos stay on your machine and the app works fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
